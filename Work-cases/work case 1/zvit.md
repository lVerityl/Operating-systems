1. Призначення Git та основні команди

Git — це система контролю версій, яка використовується для зберігання та відстеження змін у файлах проєкту. Git дозволяє зберігати історію змін, повертатися до попередніх версій файлів, а також зручно працювати над проєктом разом з іншими розробниками.

Основні дії та команди Git:

- git init — створення нового Git-репозиторію.
- git clone — копіювання існуючого репозиторію.
- git status — перегляд поточного стану файлів.
- git add — додавання змін до майбутнього комміту.
- git commit — фіксація змін у репозиторії.
- git log — перегляд історії коммітів.
- git diff — перегляд відмінностей між версіями файлів.
- git branch — створення та перегляд гілок.
- git merge — об'єднання змін із різних гілок.
- git push — відправлення локальних змін до віддаленого репозиторію.
- git pull — отримання актуальних змін із віддаленого репозиторію.

Отже, Git допомагає контролювати версії проєкту, зберігати історію змін та спрощує спільну роботу над файлами.
